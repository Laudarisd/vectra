# Vectra Web

[English](../../apps/web/README.md) · [한국어 홈](README.md)

Vectra Web은 브라우저에서 사용하는 로컬 중심 AI 작업 공간입니다.

## 주요 기능

- GGUF/llama.cpp, Ollama 및 클라우드 모델 지원
- 로컬 대화 기록
- PDF, DOCX, PPTX, XLSX, 텍스트와 이미지 첨부
- OCR과 구조화된 문서 분석
- 안전한 실시간 웹 검색
- 문서, 코드, 이미지와 차트 생성 및 다운로드

## 실행

저장소 루트에서 실행합니다.

```sh
npm install
npm run start:web
```

터미널에 표시되는 로컬 주소를 브라우저에서 열면 됩니다. 로컬 모델과 대화 데이터는 사용자의 컴퓨터에 저장됩니다.
